ULSAN365 — 산악영화제 기존 완료본 적용

최종 결정
9/18 게시물은 산악영화제로 진행한다. 단, 신규 제작이 아니라 기존 제작완료본 재사용이다. 기존 원고·메타데이터·이미지를 우선 회수하여 적용하고 같은 주제로 다시 작성하거나 이미지를 새로 생성하지 않는다.

1. WORK 최우선 작업

  1. 현재 Git 저장소·MASTER·기존 콘텐츠 폴더에서 산악영화제 기존 완료본을 먼저 찾는다.
  2. 제목, slug, 원고, 공식출처, 이미지 파일을 기존본 그대로 확인한다.
  3. 기존 완료본이 있으면 재작성·재조사·재생성하지 않는다.
  4. 대표 1 + 본문 6, 총 7개 실제 이미지 파일이 있는지 확인한다.
  5. 9/18 게시 슬롯에 적용 가능한 상태인지 확인한 뒤 build/link/UI 검증한다.
중요 — 임의 보완 금지
현재 CHAT이 확보한 자료에서는 산악영화제 기존 완료본의 정확한 제목·slug·7컷 파일명이 확인되지 않았다. 따라서 WORK가 저장소에서 기존 실물을 찾기 전까지 임의 제목, slug, 일정, 이미지 파일명을 새로 만들지 않는다.

2. 이미지 기준

  • 총 7컷: 대표 1 + 본문 6.
  • 기존 완료 이미지 우선 사용.
  • 대표 이미지만 제한적 제목형 문구 허용.
  • 본문 6컷은 원칙적으로 무문구.
  • 콜라주 한 장을 7컷 완료로 판정하지 않는다.
  • 중복 이미지, 워터마크, 가짜 공식 로고·공고문·QR·전화번호 생성 이미지 사용 금지.
