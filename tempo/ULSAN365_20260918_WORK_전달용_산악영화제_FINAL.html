9/18 산악영화제 — WORK 최종 전달용

기준: 기존 산악영화제 완료 원고 우선 재사용 / 이미지 7컷 최종 매핑 반영
처리: 중복검사 → 기존 완성본 보호 → 7컷 적용 → build/link/UI 검증 → Git 반영

최종 이미지 7컷 매핑

  1. 대표 — 산악영화제 야외 상영 분위기. 최종 확정 대표컷 사용.
  2. 본문 1 — 밤, 산 아래 잔디광장의 야외 영화 상영. 관객·스크린 중심.
  3. 본문 2 — 밝은 오후 행사장 입장 장면. 가족·방문객, 흰 텐트와 안내 부스.
  4. 본문 3 — 현대적인 실내 영화관 상영 장면. 객석 뒤에서 스크린을 바라보는 구도.
  5. 본문 4 — 야외 체험존. 어린이 인공암벽 + 가족 자연소재 공예 체험.
  6. 본문 5 — 교체 완료본 사용. 실내 토크 무대에서 감독·산악인·관객이 대화하는 장면. 기존 푸드트럭 오류컷은 폐기.
  7. 본문 6 — 이미 생성된 영남알프스 자연·산책/등산 풍경 컷 중 최종 적합본 1컷 사용. 추가 생성 금지.
폐기: 본문 5로 잘못 생성된 푸드트럭/야외 스크린 이미지는 사용하지 않는다.
금지: 산악영화제 원고 재작성, 공식정보 재조사, 정상 이미지 재생성, 본문 6 추가 생성.

WORK 실행

① 기존 산악영화제 실물 완료본 회수 → ② 위 7컷과 1:1 매핑 → ③ 이미지 수·순서·본문 배치 확인 → ④ 기존 링크 및 관련글 검증 → ⑤ production build 확인 → ⑥ PASS 시 Git 반영 후보로 확정.

최종 판정 기준

대표 1 + 본문 6 = 총 7컷이어야 한다. 본문 5는 반드시 이번 교체된 실내 토크 장면이어야 하며 오류 푸드트럭 컷이 남아 있으면 FAIL. 본문 6은 추가 생성하지 않는다.
